# Фотопортфолио — Sony ZV-E10 II

Оптимизированный сайт-портфолио под телефон и компьютер.  
Сильный акцент на фотографиях, тёмная тема, лайтбокс со свайпами.

## Структура фото

Положи свои фото в папку `images/` с такими именами:

```
images/
├── Hero.jpg     ← главное фото на первом экране
├── 01.jpg
├── 02.jpg
├── 03.jpg
├── 04.jpg
├── 05.jpg
├── 06.jpg
├── 07.jpg
├── 08.jpg
├── 09.jpg
├── 10.jpg
├── 11.jpg
├── 12.jpg
├── 13.jpg
├── 14.jpg
└── 15.jpg
```

Формат — **jpg** (можно и jpeg, но лучше именно `.jpg`).

## Как поменять категории фото

В `index.html` у каждого `.gallery-item` есть атрибут:

```html
data-category="nature"
```

Возможные значения:
- `portrait` — Портрет
- `nature` — Природа
- `street` — Улица
- `other` — Другое

Просто поменяй значение под каждое фото.

## Форма обратной связи

1. Зайди на https://formspree.io и создай форму
2. Получи endpoint вида `https://formspree.io/f/xxxxxx`
3. В `index.html` у формы добавь:

```html
action="https://formspree.io/f/xxxxxx" method="POST"
```

## Как выложить

### Netlify (самый быстрый)
1. netlify.com → зарегистрируйся
2. Перетащи папку `portfolio` в окно Deploy
3. Готово

### GitHub Pages
1. Создай репозиторий
2. Залей все файлы
3. Settings → Pages → Source: main / root
4. Сайт будет по адресу `https://ник.github.io/название-репо`
